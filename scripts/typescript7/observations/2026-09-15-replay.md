# Initial native-fixture replay

The native capture now records option declarations and caller chains. The
candidate adapter uses that provenance to execute original compiler fixtures
and keep auxiliary compilations separate. It does not feed native-generated
declaration output to TSZ.

The Linux process adapter retains absolute virtual paths, symlink targets,
ordered roots, and byte-identical inputs in a mount namespace. The native
option declarations translate numeric enums and lists into CLI values without
guessing or omitting unsupported options. Results retain complete process
streams, TSZ JSON products when available, output byte blobs, and input changes.

## Evidence

- All **32 harness tests pass**, including namespace tests for absolute paths,
  symlinks, non-UTF-8 output bytes, timeout cleanup, and host-path containment.
- The refreshed numeric-separator native observation retains its **80 passing
  leaves, one skip, and 50 baseline products**. Captured products remain
  byte-identical to the earlier release observation.
- TSZ executed **11 original fixture invocations**. All **10 auxiliary
  invocations** remain visible as unsupported adapter work. None counts as a
  passing native test.
- The executions expose missing compiler support for the native defaults
  `newLine`, `noErrorTruncation`, and `skipDefaultLibCheck`: TSZ reports TS5023.
- A production 7.0.2 CLI control compiled the hexadecimal numeric-separator
  fixture successfully in the same namespace and emitted one JS file. Its
  binary reports native commit `2bd066d87f5bafd315be9f40889d0a60b9e58e0b`,
  an unmodified tree, and version 7.0.2. This is transport evidence, not TSZ
  conformance evidence.

Ignored artifacts: `artifacts/typescript7/7.0.2-replay-inputs/`,
`7.0.2-tsz-replay-final/`, and `7.0.2-replay-cli-control-final/`.

The adapter still needs native all-phase diagnostic products, baseline
formatting, generated-output dependency replay, case-insensitive virtual hosts,
project/config handling, and the other native test drivers. No new full-corpus
conformance percentage is established.
