# Production newline compatibility

Oracle: TypeScript **7.0.2**, native commit
`2bd066d87f5bafd315be9f40889d0a60b9e58e0b`, nested corpus commit
`4d4f005c8541e0255a9d8791205fdce326e462bc`.

## Rule and owners

When `newLine` selects LF or CRLF, TypeScript uses that separator for generated
JS and declaration lines. TSZ now does this through its compiler options and
printer, following the native `internal/printer/textwriter.go` writer model.
Source literal bytes remain authored; synthesized declaration literals use
cooked values. Comment line separators are written through the printer.
Configuration and CLI enum validation share one option-schema operation.

The declaration printer retains JSDoc, pinned comments, and the existing
triple-slash reference class. Parenthesized constant literals retain native
initializer syntax in declarations. Inferred object declaration summaries use
the configured separator. No emitted-output replacement or fixture-name rule
is used.

The program capability analysis remains the sole claim owner. Plain templates
graduate declaration summaries; reference-service queries retain their typed
nonclaim until their native display matrix is implemented. Unsupported forms
still defer dependent products. No semantic cache or recursion identity changes.

## Broad observations

| Measurement | Before | After | Denominator |
| --- | ---: | ---: | ---: |
| Diagnostic passes | 1,326 | 1,328 | 12,585 selected |
| Complete JS passes | 805 | 807 | 13,806 |
| Complete DTS passes | 55 | 57 | 1,881 |
| JS product sets matching bytes | 3,394 | 3,396 | 13,806 |
| DTS product sets matching bytes | 131 | 171 | 1,881 |

Product-only matches are **not** complete test passes.

Diagnostics use the external-process runner with the locked full cache and
domain, 12 workers, printed fingerprints, and per-failure JSON artifacts.
All **12,585 stable row identities** are retained: 2,234 runnable, 10,315
unsupported, 36 skipped. Only `newLineFlagWithCRLF` and `newLineFlagWithLF`
change from failure to pass; all **906 remaining failure payloads** are
unchanged. There are no candidate crashes or timeouts.

The complete emit run retains all 13,806 stable identities and every previously
passing row and matching product set. It changes 71 candidate records: two
newly runnable newline rows and 69 declaration product sets. Forty of those
sets become byte-exact; 29 remain mismatches. No previously matching individual
output file regresses. Previously observed candidate diagnostic payloads remain
unchanged.

The raw emit regression gate **exits 1**: five native-oracle invocations time
out at the unchanged five-second limit under 12-way execution. All five TSZ
invocations finish. Serial focused observations at the same timeout reproduce
each original native result exactly and each candidate payload unchanged:
arithmetic invalid operands, comparison call signatures, comparison constructor
signatures, `giant`, and the ES2015 regular-expression-scanning variant.
These focused records do not replace rows in the raw full report or turn that
gate green. The focused regex filter also selects two existing unsupported
variants; they remain unsupported.

Eighteen other oracle JS manifests differ because the old adapter embeds random
staging paths in JSX development output. The later stable-path adapter fixes
that harness issue and passes its focused repeated-run contracts; it has not
yet had a full-corpus observation. Two more oracle records are the newly
transported newline cases.

The old fourslash launcher exits before executing tests because its generated
JavaScript harness is absent. Production TypeScript 7 does not provide the old
TypeScript 6 API. No fourslash parity is claimed.
