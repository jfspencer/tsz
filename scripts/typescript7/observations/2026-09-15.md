## Declaration-only and command-line phase selection

Structural rules ported from production 7.0.2:

- `internal/outputpaths/outputpaths.go`: `emitDeclarationOnly` suppresses JS
  paths; `declaration` requests DTS paths. Program options own product selection;
  capability checks and emit planning consume the same selection.
- `internal/compiler/program.go:GetDiagnosticsOfAnyProgram`: config errors
  remain additive, followed by the first nonempty syntax/program/semantic
  phase. Emit-time errors remain additive. Raw semantic service queries still
  check independent declarations and retain their own completion.
- `internal/compiler/program.go` and
  `internal/tsoptions/tsconfigparsing.go:ForEachPropertyAssignment`: TS5069
  requires `declaration` or `composite`; its span uses the first authored
  matching option key, including duplicate keys.
- `internal/compiler/emitter.go`: an absent output target does not count as
  skipped emit. Invalid declaration-only options with `noEmit` therefore exit
  2, unless `noEmitOnError` blocks the invocation.

The exact local oracle matrix improved from **0/11 to 9/11** matching stdout,
stderr, exit, and emitted file bytes. The two remaining differences are exit 3
for TSZ parser recovery; diagnostic text now matches. Evidence:
`artifacts/typescript7/emit-declaration-only/{oracle-matrix,matrix-comparison}.json`.

Focused upstream observations:

- Diagnostic filter `declFileEmitDeclarationOnly`: two exact passes and one
  unsupported case, out of three candidates.
- Emit filter `DeclarationOnly`: one exact JS pass, one incomplete case, and
  two unsupported rows. The three DTS rows remain incomplete/unsupported.
- `declFileEmitDeclarationOnly` still lacks `helloworld.d.ts`; the option port
  does not establish support for all syntax or declaration summaries it uses.

The adjacent tests cover renamed declarations, reversed roots, TS/MTS/CTS
extensions, generic functions, inherited options, output directories, option
ordering/duplicates, false values, `noEmit`, `noEmitOnError`, and independent
JS/DTS map capability claims. `composite: true` remains explicitly incomplete
until project-build semantics are implemented; it is no longer an unknown option.

Owner consolidation removes a redundant capability wrapper, duplicate product
selection, and duplicate terminal dispatch. Expected output paths replace two
separate output-count checks. Handwritten compiler Rust falls from 44,931 to
44,929 lines; the config central module falls from 1,301 to 1,291. These remain
well above the rewrite's 15,000-line readiness target.

Validation includes the Rust workspace tests, seven seed oracle cases, strict
Clippy, architecture guard and its 60 tests, and the context audit. Three lint
findings exposed by the installed toolchain were also fixed: a duplicate test
module import, a redundant test clone, and UTF-16 chunk iteration using Rust
array chunks. Broad after-change conformance has not yet been measured.
